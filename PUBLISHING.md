# Recommended publishing setup

## Cheapest clean setup
- Hosting: GitHub Pages — $0
- Domain: buy separately from a registrar — typically the only recurring cost
- Site maintenance: edit one HTML file

## Why this setup fits Heartland Mile
This is primarily a booking / credibility site, not an ecommerce store. A fast one-page site gives venue bookers everything they need: identity, sound, live video, representative set material, credentials, and a contact path.

## Optional upgrades later
- Add an actual Heartland Mile band photo as the hero background.
- Add a dedicated upcoming-shows section once there are confirmed Heartland Mile dates.
- Replace Instagram booking with a dedicated email address.
- Add downloadable stage plot / EPK PDF.
- Add a mailing-list form using Buttondown, Mailchimp, Kit, or another provider.
- Add Plausible or another privacy-friendly analytics tool.
