# Heartland Mile website

A lightweight one-page site for Heartland Mile. It uses only HTML/CSS/JavaScript, so it can be hosted free on GitHub Pages, Cloudflare Pages, Netlify, etc.

## Before publishing

1. Open `index.html` in a browser to preview it.
2. Replace the booking buttons with a preferred booking email if desired.
3. Add a real Heartland Mile band photo or logo later if desired; the current design intentionally works without one.
4. Pick a domain. Examples to check: `heartlandmileband.com`, `heartlandmilemusic.com`, or a shorter variation.

## Free GitHub Pages publishing

1. Create a GitHub repository (for example, `heartland-mile`).
2. Upload `index.html` to the repository root.
3. In repository Settings → Pages, choose the main branch and root folder.
4. GitHub will provide a free `github.io` URL.
5. If you buy a custom domain, add it under Settings → Pages → Custom domain and update DNS at your domain registrar.
